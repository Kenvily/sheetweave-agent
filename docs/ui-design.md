# 周报工作台界面设计

更新：2026-10-12。依据实际 Flask / Jinja2 页面与 ui-ux-pro-max 的极简企业工具、表单、键盘焦点建议整理。使用原生 HTML、CSS 和现有 JavaScript，不引入前端框架、字体 CDN 或组件依赖。

## 使用场景与页面职责

- **首页**：上传 CSV/XLSX，确认规则、日期和范围，选择整理方式。三个表单分组对应来源、范围、内容。预览审核是主操作，直接下载为次操作。高级字段映射默认折叠；原文模式隐藏并禁用模型选择，自定义模式展开要求输入。侧栏显示配置摘要与示例入口，匿名统计置于页面底部。
- **审核页**：顶部显示报告版本、来源与内容块数量、候选告警数量。桌面保留来源、当前内容和文档三栏；窄屏改为两栏或单栏并提供面板锚点。当前内容优先显示，人工编辑按需展开。模型候选、谨慎采用、原文与当前内容 Diff、编辑前后确认 Diff 使用已有独立流程。
- **帮助页**：与首页共享导航，四步说明、示例下载、规则与模式解释、常见问题分层呈现。

告警摘要统计所有尚未通过事实校验的模型候选，即使已人工采用，仍提示核对；不会修改其校验状态。审核会话仍保留两小时，系统没有历史报告列表。

## 视觉与交互规则

白色文档区域、浅灰工作台背景、深色正文和深青色主操作；颜色通过 `src/static/styles.css` 的语义变量管理。正文使用本机中文无衬线字体，文档预览保留原有文档字体。按钮保留文字，状态同时使用文案表达，避免依赖颜色识别。

共享导航位于 `src/templates/_navigation.html`，当前页面通过 `aria-current` 标记。支持跳转主要内容、可见键盘焦点、原生表单标签、编辑框独立标签、减少动态效果设置。生成弹层隔离背景焦点，支持取消和 Escape；人工修改使用原生 dialog 显示确认 Diff。已有 HTML/PDF 页签补充面板关联与方向键导航。

移动端配置与审核改为单列，辅助侧栏置于配置后。按钮至少 44px 高，普通输入使用 16px 字体；长文本允许换行。真实来源表格允许在局部容器滚动，不应让整页横向溢出。

## 验证边界

137 项 pytest 回归及 Ruff 检查；Chromium 使用合成数据与 Mock 验证首页、审核页在 375/768/1024/1440px 的布局，帮助页手机纵横屏，原文与流式预览、人工编辑 Diff 的返回/确认、DOCX 下载。截图保存在忽略 Git 的 `outputs/ui-*.png`。

内容生成、事实检查、候选采用、规范化、DOCX 渲染、统计与会话逻辑不因此次界面调整改变。未做真实外部模型调用、全浏览器兼容或完整屏幕阅读器验收。

## 三栏阅读与定位

各栏标题区提供独立缩放（75%、85%、100%、115%、125%、150%），标题与操作控件不随正文缩放。来源和内容分别缩放各自列表，右栏只缩放 HTML 文档；PDF 使用阅读器内置缩放。设置和专注模式仅保存在浏览器 localStorage，不保存周报正文，也不改变 DOCX 字体、排版或内容。关闭本地存储时当前页面仍可使用。

点击来源、审核块或 HTML 条目进行双向高亮与定位；滚动容器按目标实际坐标和标题高度定位，支持缩放后的坐标与减少动态效果。PDF 显示时保留当前定位，返回 HTML 后定位到对应块。桌面三栏滚动局限于各栏，窄屏按页面布局滚动。长块优先露出起始内容，不能保证整块一次显示。

右上角“专注审核”收起全站导航与辅助描述，增加正文可视高度；同一按钮可退出。浏览器用 30 个合成项目验证三向联动、定位不被标题遮挡、独立缩放、刷新记忆、专注高度与窄屏无整页溢出。
