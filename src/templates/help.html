规则与方案

已保存方案
所有表格先进入“方案适配”，确认字段、内容保留策略和格式，试生成并保存后在主页选用。示例文件也使用此流程。

内容处理模式

原文保留
适合原表逻辑正确的场景，保留原有顺序与显式层级，不调用模型。
规范润色（可选补充要求）
适合原表逻辑不清的场景，允许重分条与结构重组，可选补充要求；提示性差异不阻止采用，关键事实冲突仍回退。

常见问题

没有显示周次或工作表

CSV 没有工作表；通用单周格式也没有周次选项。XLSX 请先选择文件，等待页面读取完成。

生成过程中显示的候选可以直接导出吗？

增量显示的模型候选尚未校验。生成完成后，系统会校验并进入审核页；下载使用当前已采用、经过规范化的内容。

模型候选被回退

候选涉及数字、指标、版本、日期或状态冲突时不会自动进入 DOCX。请对照来源后编辑，或勾选确认告警后谨慎采用；也可只重新生成该内容块。

PDF 预览不可用

PDF 依赖服务器安装 LibreOffice。即使不可用，HTML 预览与 DOCX 下载仍可正常使用。

任务一直显示排队

任务由独立后台进程处理。请确认服务器已启动后台 Worker；多人同时生成时也可能等待可用处理容量。刷新当前页面会重新连接任务。

刷新后找不到报告

审核会话默认仅保留两小时。过期后需重新上传，系统不保存历史周报正文。

页面只显示聚合统计：累计 {{ usage_metrics.total_generations }} 次、本周 {{ usage_metrics.weekly_generations }} 次、访客 {{ usage_metrics.estimated_visitors }}、访问次数 {{ usage_metrics.page_views }}。统计不保存周报正文、姓名、账号或 IP。

陌生表格与新格式

进入方案适配，确认字段、状态取舍和段落格式，离线试生成后保存。方案长期保存在服务器，下次直接选用，无需重复上传模板。

首次识别需确认脱敏样例及模板片段外发，后台自动填入字段、目录和格式，最多两轮方案建议；原文试生成不调用模型。表格、文本框等复杂模板会明确提示不支持。更新方案不会改变已提交任务或审核会话的规则。
